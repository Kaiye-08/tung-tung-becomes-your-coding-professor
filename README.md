# Tung Tung Tung Sahur becomes your Coding Professor 🏏

**Your strictest computer science professor has arrived. And he's brought a bat.**

Welcome to a chaotic, brainrot-inspired coding game where the legendary Tung Tung Tung Sahur becomes your personal computer science professor. Learn programming fundamentals, survive quizzes, earn points, and try not to get bonked along the way.

## 🎮 About the Game

Triple T is a quirky educational game that combines computer science lessons with meme-inspired humor and interactive quizzes.

Your professor genuinely wants you to succeed. Unfortunately, his teaching methods are... unconventional.

- 📚 **Learn:** Study computer science and programming fundamentals.
- 🧠 **Take quizzes:** Test your understanding after each lesson.
- 🏏 **Get bonked:** Answer incorrectly and face your professor's legendary punishment.
- 🎉 **Get celebrated:** Answer correctly and earn his approval.
- 🔥 **Build streaks:** Keep answering correctly to rack up rewards.
- 🏆 **Level up:** Earn points as you progress through your coding education.

## ✨ Features

- Interactive lessons and quizzes
- Animated character reactions
- Correct-answer celebrations and wrong-answer bonks
- Points, streaks, and progression mechanics
- Sound effects and audio interactions
- A playful, nostalgic game-inspired interface
- Programming education wrapped in internet humor

## 🛠️ Built With

- **HTML5** for the game structure
- **CSS3** for styling, animations, and visual effects
- **JavaScript** for game logic, lessons, quizzes, audio, and progression

No heavy framework required. Just web technologies doing their thing.

## 🚀 Getting Started

### Play Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Kaiye-08/tung-tung-coding-professor.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Meet your professor. Try to make him proud.

For the best experience, use a modern browser with JavaScript enabled.
